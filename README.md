# LowShelf Website
## Project Overview
The LowShelf website was developed for Lowveld Shelving and Racking. Its purpose is to introduce the business, display its products and services, provide business information and allow potential customers to submit enquiries or request quotations.

The website was developed using HTML5, CSS3 and JavaScript.

## Technologies Used
HTML5 – Website structure and content.
CSS3 – Website styling and responsive layouts.
JavaScript – Interactive website functionality.
Visual Studio Code – Development environment.
Git and GitHub – Version control and source code management.
Formspree – External form-handling service.
Netlify – Website deployment platform.
## Website Pages
The website contains the following pages:

index.html – Homepage.
about.html – About Us page.
products.html – Products and product search.
gallery.html – Product and business gallery.
quote.html – Request a Quote form.
contact.html – Contact Us page.
sitemap.html – Human-readable website sitemap.
## Main Features
Website Navigation
The website includes navigation links connecting the main pages, allowing visitors to move between the homepage, About Us, Products, Gallery, Request a Quote, Contact Us and Sitemap pages.

JavaScript Functionality
JavaScript is used to display a welcome message on the homepage and provide interactive functionality.

A product search feature has been introduced on the Products page, including category suggestion buttons. Manual keyword searching is subject to final testing.

Forms
The website includes a Request a Quote form and a Contact Us form.

Formspree is used as the external form-handling service. The form endpoints, field names and actual receipt of submissions must be verified before the forms are considered fully functional.

## Search Engine Optimisation
SEO improvements include:

Page-specific titles.

Image alternative text.
HTML sitemap.

robots.txt file.
Responsive Design
CSS media queries and responsive styling are used to support different screen sizes, including desktop, laptop and mobile devices.

## Testing
The website should be tested to confirm:

All navigation links work correctly.
All pages load correctly.
Images display properly.
Product search returns the expected results.
Forms validate required information.
Formspree receives valid submissions.
The sitemap is accessible.
The website layout works on different screen sizes.
JavaScript runs without unexplained browser console errors.
Testing results are recorded in documentation/TESTING.md.

Features that have not been verified should be marked as pending or not tested.

## Deployment
The website is intended to be deployed using Netlify.

The final deployment address and live website link will be added after successful deployment.

The sitemap.xml and robots.txt files must be updated to use the final published website address.
